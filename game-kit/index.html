Get started

Install once. Ship forever.

Two lines in your terminal, then one command in any game you work on.

Add the team's kit

claude plugin marketplace add evolvai-me/game-kit

Needs access to the EvolvAI GitHub team.

Install the plugin

claude plugin install game-kit@evolvai-game-kit

Adds the commands to Claude Code.

Ship

/game-kit:ship

Run it inside a game's folder. Answer one question. Done.

New game? Run /game-kit:ship anyway: it checks what's missing and offers to set the game up.

Speed without the scary parts

Eight checks before anything reaches Google Play

  • Released from the main branch
  • Version is new to Google Play
  • Release notes within Play's limit
  • Every automated test passes
  • Signed with the game's own key
  • Store page text and images fit Play's rules
  • Store answers from a reviewed file
  • Ready for Play's 16 KB requirement

The commands

Four commands. Most days, one.

/game-kit:shipRelease the next versionTo Google Play's test track. Add closed to send it on to testers.
/game-kit:new-gameSet up a new gameEverything a game needs to start releasing.
/game-kit:consoleFill Play Console formsThe ones Google offers no API for, with your approval.
/game-kit:release-prepReview before releaseJust the release change, for a careful look first.
